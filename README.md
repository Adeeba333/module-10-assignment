# JavaScript Function Assignment

This project contains 8 JavaScript functions for basic mathematical calculations, array manipulation, string operations, and leap-year validation.

## Functions
- Calculate difference
- Check odd numbers
- Find minimum value
- Filter even numbers
- Sort numbers in descending order
- Lowercase the first letter
- Calculate average
- Check leap years

## How to Run
1. Install [Node.js](https://nodejs.org/).
2. Open the terminal in the project folder.
3. Run `node index.js` to see the output.

**Technology:** JavaScript, Node.js
